# 隐藏文字（折线版）单文件工具

把文字藏在人字纹条纹里：人眼可以辨认，但机器很难检测。打开即用，无需安装、无需联网。

## 在线使用

下载本仓库的 `index.html`，双击用任意浏览器打开即可（手机浏览器也可）。

## 功能

- 输入文字实时隐藏到折线条纹中，可调：
  - 宽 / 高（条纹粗细）、条纹旋转（0–360°）、条纹缩放
  - 文字大小 / 粗细 / 行距 / 间距 / 透明度
- 导入图片（与文字共存，独立图层）
- 文字、图片均可拖动；手机端支持双指捏合缩放 + 旋转
- 数值方案：把当前参数保存为方案，随时切换
- 导出 PNG / JPG
- 替换字体（本地字体文件）

## Android APK

仓库内的 `隐藏文字.apk`（约 37 KB，零权限）可直接安装使用，功能与网页版一致，数据保存在本机（WebView localStorage）。

## 从源码构建

本仓库的 `index.html` 与 `隐藏文字.apk` 都是由 `assemble_single.py` 在原折线版前端基础上自动注入功能生成的，原前端代码逐字保留、只在外围加功能。

```bash
# 1) 准备原始折线版源码目录（含 index.html / index.js / index.css 等）
#    默认路径见 assemble_single.py 顶部的 SRC_DIR，可按需修改
# 2) 运行装配脚本，生成新的单文件版 index.html
python assemble_single.py
# 3) 生成的文件位于：单文件版目录/index.html
#    再按 APK 构建说明（见下方或项目 wiki）打包成 apk
```

> APK 的构建使用本地 Android 构建工具链（aapt2 → javac → d8 → zipalign → apksigner），
> 把生成的 `index.html` 放进 `assets/` 后按标准流程打包、签名即可。
